## Decision Log

Record decisions that affect scope, UX, brand, or technology.

| 2025-01-27 | Android Framework: Kotlin Native | Kotlin Native (Jetpack Compose) / Flutter (Dart) / Java | Kotlin is official Android language, modern, performant. Jetpack Compose provides modern UI. Clean Architecture (MVVM) enables iOS-ready structure by sharing API layer and patterns. Better RTL/Hebrew support than Flutter. Aligns with Android-first approach; iOS app can be built later using same REST API with SwiftUI. | Project will use Kotlin with Jetpack Compose. Architecture will follow MVVM pattern with clear separation of concerns. Business logic in ViewModels, data layer uses Repository pattern. | TBD |
| 2025-01-27 | Backend Framework: PHP Laravel | PHP Laravel / Python FastAPI / Node.js Express / Go / Java Spring Boot | Laravel has excellent native MySQL support (meeting preference). Very cost-effective hosting options (important for 100k ILS budget). Rich ecosystem with built-in features (auth, validation, ORM). JWT libraries readily available. Mature, stable, good documentation. Python FastAPI considered but hosting typically costs more. | Backend will be Laravel application. Will use Eloquent ORM for database, Sanctum or JWT for authentication. API structure follows RESTful patterns defined in API spec. | TBD |
| 2025-01-27 | Infrastructure: VPS Hosting | VPS (DigitalOcean/Linode/etc.) / Shared Hosting / AWS/GCP / Other Cloud | VPS offers cost-effectiveness (~$6-12 USD/month) while providing full control and scalability path. Better than shared hosting for API performance and control. Avoids cloud vendor lock-in and reduces costs vs managed cloud services. Can start small and scale incrementally. MySQL can run on same VPS initially. | Will provision VPS for backend and database. Will use Linux (Ubuntu LTS) with Nginx as reverse proxy, PHP-FPM, MySQL 8+. SSL certificates via Let's Encrypt. | TBD |
| 2025-01-27 | Android Architecture Pattern: MVVM | MVVM / MVI / MVP / Clean Architecture | MVVM provides clear separation: View (Compose UI), ViewModel (business logic), Model (Repository/Data layer). Enables testability and maintainability. Aligns with Android best practices and Jetpack Compose. Repository pattern allows easy API abstraction and caching strategy. | Code structure: ui/ (Composables), viewmodel/ (ViewModels), repository/ (data access), model/ (data classes), network/ (API clients). Use StateFlow/Flow for reactive state management. | TBD |
| 2025-01-27 | Android Minimum SDK: API 24 (Android 7.0) | API 21+ / API 24+ / API 26+ / API 28+ | API 24 covers ~95%+ of Android devices while enabling modern features. Balances compatibility with feature access. Allows use of newer Android APIs without fragmentation concerns. | gradle.properties will set minSdkVersion 24, targetSdkVersion will be latest stable (34+). | TBD |
| 2025-01-27 | Android Networking: Retrofit + OkHttp | Retrofit+OkHttp / Ktor / Volley / Manual HttpURLConnection | Retrofit is industry standard for REST APIs, type-safe, integrates well with Kotlin coroutines. OkHttp provides HTTP client with interceptors for auth headers. Both have excellent documentation and community support. Enables easy JWT token refresh handling. | Will use Retrofit for API service interfaces, OkHttp for client configuration. Will add interceptors for JWT token injection and refresh logic. | TBD |
| 2025-01-27 | Android Dependency Injection: Hilt | Hilt / Koin / Dagger / Manual DI | Hilt is Google's official DI solution built on Dagger, integrates seamlessly with Android. Reduces boilerplate, provides Android-specific scopes (Activity, ViewModel). Better compile-time safety than Koin. Standard choice for modern Android apps. | Will use Hilt for dependency injection throughout app. Application, Activity, and ViewModel scopes will be configured. | TBD |
| 2025-01-27 | Laravel Authentication: Laravel Sanctum | Laravel Sanctum / Laravel Passport / tymon/jwt-auth | Sanctum is lightweight, built-in Laravel package perfect for SPA/mobile API authentication. Supports token-based auth with simple API tokens. Easier setup than Passport, sufficient for MVP needs. Can migrate to Passport later if OAuth server needed. | Backend will use Sanctum for API token authentication. JWT-like tokens will be issued after social auth callback. | TBD |
| 2025-01-27 | Image/Video Handling: Android Media3 + Coil | Media3 / ExoPlayer / Coil / Glide | Media3 (formerly ExoPlayer) is modern, maintained for video playback. Coil is Kotlin-first, Compose-friendly image loading library, lighter than Glide. Both integrate well with Compose and coroutines. Coil handles caching, transformations efficiently. | Will use Coil for image loading/composables, Media3 for video playback in app. Video upload will use multipart/form-data via Retrofit. | TBD |
| 2025-01-27 | Database: MySQL 8+ (as specified) | MySQL 8+ / PostgreSQL / SQLite / Other | MySQL 8+ is specified in Creative Brief as preference. utf8mb4 character set required for Hebrew/RTL support. Laravel Eloquent provides excellent MySQL support. Same VPS can host MySQL initially. | Database will be MySQL 8+ with utf8mb4_unicode_ci collation. DDL already defined in 11-MySQL-DDL.sql. Will use Eloquent migrations. | TBD |
