# Knesset Data Integration

This document describes the integration of Knesset (Israeli Parliament) data into the Day Party platform.

## Architecture Overview

The Knesset data is stored in a **separate SQLite database** that is:
- **Downloaded** by the mobile app from the server
- **Stored locally** on the device
- **Queried locally** for fast, offline access
- **Updated automatically** when new data is available

This approach is ideal because:
- Knesset database is large (~100MB+) but rarely changes
- Queries are fast (local database)
- Works offline after initial download
- Doesn't impact Day Party API performance

## Components

### 1. Backend (Node.js)

#### Downloader Scripts (`backend/knesset-downloader/`)
- **`odata_downloader.py`** - Downloads data from Knesset OData API
- **`initialize_database.py`** - Builds SQLite database from JSON files
- **`requirements.txt`** - Python dependencies

#### API Endpoints (`backend/src/controllers/knesset-database.controller.ts`)
- **`GET /api/knesset-database/info`** - Returns database file info (last modified, size)
- **`GET /api/knesset-database/download`** - Downloads the SQLite database file

#### Database Location
- Database file: `backend/data/knesset_data.db`
- Generated by Python scripts from JSON files

### 2. Mobile App (Flutter)

#### Service (`lib/services/knesset/knesset_database_service.dart`)
- Downloads database from server
- Falls back to bundled database in assets
- Manages local SQLite database
- Provides query methods

#### Provider (`lib/providers/knesset/knesset_database_provider.dart`)
- Provider pattern for accessing Knesset data
- Methods: `getAllBills()`, `getBillById()`, `getCommitteeMap()`

#### Models (`lib/models/knesset/knesset_bill.dart`)
- `KnessetBill` model for bills/laws

## Setup Instructions

### Backend Setup

1. **Install Python dependencies:**
   ```bash
   cd backend/knesset-downloader
   pip install -r requirements.txt
   ```

2. **Download Knesset data:**
   ```bash
   # Download bills
   python odata_downloader.py KNS_Bill BillID 200 data/_KNS_Bill.json --top 100
   
   # Download other tables as needed
   python odata_downloader.py KNS_Person PersonID 200 data/_KNS_Person.json --top 100
   python odata_downloader.py KNS_Committee CommitteeID 50 data/_KNS_Committee.json --top 100
   python odata_downloader.py KNS_Status StatusID 50 data/_KNS_Status.json --top 100
   ```

3. **Build SQLite database:**
   ```bash
   python initialize_database.py
   ```
   
   This creates `backend/data/knesset_data.db`

4. **Copy database to assets (optional, for first-time app installs):**
   ```bash
   copy backend\data\knesset_data.db day_party_flutter\assets\data\knesset_data.db
   ```

### Mobile App Setup

1. **Install Flutter dependencies:**
   ```bash
   cd day_party_flutter
   flutter pub get
   ```

2. **Add provider to main app:**
   ```dart
   import 'providers/knesset/knesset_database_provider.dart';
   
   // In main.dart, add to providers:
   ChangeNotifierProvider(create: (_) => KnessetDatabaseProvider()),
   ```

3. **Use in screens:**
   ```dart
   final knessetProvider = Provider.of<KnessetDatabaseProvider>(context);
   final bills = await knessetProvider.getAllBills();
   ```

## Updating Knesset Data

### Regular Updates

1. **Download latest data:**
   ```bash
   cd backend/knesset-downloader
   python odata_downloader.py KNS_Bill BillID 200 data/_KNS_Bill.json --top 100
   # ... download other tables
   ```

2. **Rebuild database:**
   ```bash
   python initialize_database.py
   ```

3. **Deploy updated database:**
   - Copy `knesset_data.db` to server at `backend/data/knesset_data.db`
   - Mobile apps will automatically detect and download the update

### Mobile App Update Flow

1. App checks `/api/knesset-database/info` on startup
2. Compares server's `lastModifiedUtc` with local stored value
3. If newer, downloads database from `/api/knesset-database/download`
4. Replaces local database
5. Falls back to bundled database if download fails

## Usage Examples

### Query Bills

```dart
final provider = Provider.of<KnessetDatabaseProvider>(context);

// Get all bills
final bills = await provider.getAllBills();

// Get specific bill
final bill = await provider.getBillById(2156160);

// Get committee map
final committees = await provider.getCommitteeMap();
```

### Display Bill Information

```dart
ListView.builder(
  itemCount: bills.length,
  itemBuilder: (context, index) {
    final bill = bills[index];
    return ListTile(
      title: Text(bill.name),
      subtitle: Text('Knesset ${bill.knessetNum}'),
      trailing: Text(bill.statusDesc ?? ''),
    );
  },
)
```

## Notes

- The database is read-only on the client (no writes)
- Updates are infrequent (Knesset data changes slowly)
- Database size is manageable (~100-200MB)
- All queries are local (fast, offline-capable)
- Server only serves the file, doesn't query it
