## Creative Brief

### Project Name
Day Party (מפלגת ד"י — דמוקרטיה ישירה)

### One-liner
A platform where users can discuss and vote on all matters.

### Goal / Problem
Enable large-scale, accessible civic deliberation and decision-making by providing structured discussion spaces and voting mechanisms.

### Audience
Primary: Israeli users interested in current affairs and civic participation.
Secondary: Organizers/moderators facilitating discussions and votes.
### Scope (In / Out)
In (MVP Android-first):
- Registration and sign-in (email/phone + basic profile)
- Topic spaces (e.g., national issues, local issues) and threads
- Structured discussion: posts, comments, reactions
- Voting mechanisms: single-choice and multiple-choice polls with deadlines
- Basic moderation: report content, hide/remove by moderators
- Notifications: essential (e.g., poll opened/closing, mentions)
- Hebrew-first UI; RTL support

Out (post-MVP / later):
- Delegated/liquid democracy
- Advanced identity verification (e.g., gov ID) beyond basic verification
- Real-time chat and live audio/video rooms
- Complex governance workflows (petitions → legislation)
- Desktop web parity; iOS app build (planned after Android MVP)
### Success Metrics
- Android MVP shipped to Play Store
- Registered users: initial target (TBD) within first 30/60/90 days
- Basic engagement: discussion posts, votes cast (baseline to be set post-MVP)
### Constraints (Time, Budget, Tech, Brand, Legal, Accessibility)
Time: Ship Android app to Play Store within 12 months.
Budget: 100,000 ILS total (design, build, infra, distribution).
Tech: Android-first with iOS-ready architecture; MySQL preferred; cost-conscious hosting.
Brand: TBD (to define tone/visuals); must communicate trust, neutrality, clarity.
Legal: Respect privacy laws; community guidelines and admin-only moderation policy required.
Accessibility: As accessible as possible; prioritize RTL, color contrast, readable typography.
### Tone & Brand Keywords
Transparency, sensible, welcoming, engaging. (Also: clear, trustworthy, inclusive, neutral, practical.)
### Inspiration (links)
TBD (skip liquid democracy). Shortlist to review:
- Decidim — participatory democracy platform
- Loomio — group decision-making
- Pol.is — large-scale opinion mapping
- Kialo — structured debate
- Discourse — forum mechanics and moderation
### Deliverables
Complete design up to implementation:
- Creative brief v1.0
- Information architecture and core user flows
- Wireframes and high-fidelity UI for Android MVP (RTL-aware)
- Design system foundations (colors, type, components)
- Data model and initial DB tables
- Chosen technologies for backend and frontend (Android + server)
- Analytics plan and baseline KPIs (registration, posting, voting)
### Platforms
Android-first implementation, with architecture enabling easy iOS support.
Desktop browser experience is secondary priority for later.
