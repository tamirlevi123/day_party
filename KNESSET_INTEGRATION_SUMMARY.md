# Knesset Integration - Summary

## ✅ Integration Complete

The Knesset data integration has been successfully added to the Day Party platform.

## What Was Added

### Backend (Node.js)

1. **Python Downloader Scripts** (`backend/knesset-downloader/`)
   - `odata_downloader.py` - Downloads from Knesset OData API
   - `initialize_database.py` - Builds SQLite database
   - `requirements.txt` - Python dependencies

2. **API Endpoints** (`backend/src/controllers/knesset-database.controller.ts`)
   - `GET /api/knesset-database/info` - Database metadata
   - `GET /api/knesset-database/download` - Download database file

3. **Routes** (`backend/src/routes/knesset-database.routes.ts`)
   - Integrated into main router

4. **Database Location** (`backend/data/knesset_data.db`)
   - SQLite database file (generated by Python scripts)

### Mobile App (Flutter)

1. **Dependencies Added** (`day_party_flutter/pubspec.yaml`)
   - `sqflite` - SQLite database
   - `path_provider` - File paths
   - `http` - Download database
   - `shared_preferences` - Store update timestamp

2. **Service** (`lib/services/knesset/knesset_database_service.dart`)
   - Downloads database from server
   - Falls back to bundled assets
   - Auto-updates when new version available
   - Local SQLite queries

3. **Provider** (`lib/providers/knesset/knesset_database_provider.dart`)
   - Provider pattern for accessing Knesset data
   - Methods: `getAllBills()`, `getBillById()`, `getCommitteeMap()`

4. **Model** (`lib/models/knesset/knesset_bill.dart`)
   - `KnessetBill` model with JSON parsing

5. **Assets** (`assets/data/knesset_data.db`)
   - Directory created for bundled database (optional)

## How It Works

1. **Server**: Stores SQLite database at `backend/data/knesset_data.db`
2. **Mobile App**: 
   - Checks `/api/knesset-database/info` on startup
   - Downloads database if newer version available
   - Falls back to bundled database if download fails
   - All queries run locally (fast, offline-capable)

## Next Steps

### 1. Download Initial Data

```bash
cd backend/knesset-downloader
pip install -r requirements.txt
python odata_downloader.py KNS_Bill BillID 200 data/_KNS_Bill.json --top 100
python initialize_database.py
```

### 2. Add Provider to Main App

In `day_party_flutter/lib/main.dart`, add to providers:

```dart
import 'providers/knesset/knesset_database_provider.dart';

// In MultiProvider:
ChangeNotifierProvider(create: (_) => KnessetDatabaseProvider()),
```

### 3. Install Flutter Dependencies

```bash
cd day_party_flutter
flutter pub get
```

### 4. Test the Integration

```dart
// Example usage in a screen:
final provider = Provider.of<KnessetDatabaseProvider>(context);
final bills = await provider.getAllBills();
```

## Benefits

- ✅ **Fast queries** - Local database, no network latency
- ✅ **Offline capable** - Works without internet after initial download
- ✅ **Auto-updates** - Detects and downloads new versions automatically
- ✅ **Scalable** - Large dataset doesn't impact API performance
- ✅ **Efficient** - Database downloaded once, not queried repeatedly
